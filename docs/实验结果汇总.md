## 三、真实 LLM API 增强说明

- API 提供商：小米 MiMo（OpenAI-compatible 接口）
- 使用模型：mimo-v2.5-pro
- 生成候选样本：59 条（目标 100 条，部分类型源样本不足）
- 质量过滤后保留：59 条（全部通过）
- 失败请求：4 条（API 返回空内容）
- 增强样本类型分布：colloquial=20, transition=20, degree=8, negation=8, implicit=3
- 增强样本 label 分布：label=0: 20, label=1: 39

---

## 四、核心结论

1. **llm_real_aug 在标准 test 上表现最好**：Test Macro-F1 = 0.9244，比 baseline 提升 +0.84pp。

2. **llm_real_aug+distill 在 hard_test 上表现最好**：Hard Macro-F1 = 0.9259，比 baseline 提升 +2.71pp。

3. **真实大模型增强显著优于模板增强**：llm_real_aug（+1.67pp）vs template_aug（+1.01pp）。

4. **增强与蒸馏存在叠加收益**：llm_real_aug+distill（+2.71pp）> 单独 llm_real_aug（+1.67pp）+ 单独 distill（+0.95pp）的简单加和预期。

5. **蒸馏在标准 test 上略有损失，但在困难样本上带来更大收益**：
   - llm_real_aug: Test=0.9244, Hard=0.9155
   - llm_real_aug+distill: Test=0.9143（-1.01pp）, Hard=0.9259（+1.04pp）
   - 说明蒸馏更有利于复杂表达的鲁棒性提升。

## 五、实验条件说明

|---|---|
| 数据集 | ChnSentiCorp（train=8249, dev=1178, test=1178） |

| 学生模型 | TextCNN（~1.37M 参数） |
| 蒸馏参数 | T=2.0, alpha=0.5, epochs=15, patience=3 |
| GPU | NVIDIA GeForce RTX 3060 Laptop GPU |
| 环境 | Python 3.9, PyTorch 2.6.0+cu118, transformers 4.57.6 |

## 六、注意事项

1. hard_test 是规则初筛困难集，不是人工精标金标准，后续报告中应说明局限。
2. 真实 LLM 增强样本仅 59 条，如果增加到 200+ 条可能效果更好。
3. 当前只完成了 TextCNN 的完整消融实验，BiLSTM 的增强/蒸馏实验未做。
4. BERT/MacBERT 的增强实验未做（它们本身已是强基线）。
5. 所有结果基于单次训练（seed=42），未做多次随机种子平均。
