## 一、项目任务概述

**题目：** 基于大模型辅助困难样本增强与轻量蒸馏的中文短文本情感分析

**任务：** 中文短文本情感二分类（正向/负向），数据集为 ChnSentiCorp。

**核心目标：** 比较不同模型（TextCNN/BiLSTM/BERT/MacBERT）、困难样本增强（模板/真实 LLM API）、知识蒸馏（MacBERT→TextCNN）对标准测试集和困难样本集的影响，验证"大模型辅助困难样本增强 + 轻量蒸馏"策略的有效性。

## 三、四模型基线实验结果

| Model | Test Accuracy | Test Macro-F1 | Hard Accuracy | Hard Macro-F1 |
|---|---|---|---|---|
| TextCNN | 0.9160 | 0.9160 | 0.9000 | 0.8988 |
| BiLSTM | 0.8888 | 0.8887 | 0.8833 | 0.8813 |
| BERT | 0.9015 | 0.9015 | 0.8867 | 0.8848 |
| MacBERT | 0.8922 | 0.8921 | 0.9000 | 0.8992 |

**分析：**

- TextCNN 在标准 test 上表现最好（F1=0.9160），说明在 ChnSentiCorp 这种规模较小的中文短文本任务中，轻量 CNN 模型仍具有较强竞争力。
- MacBERT 和 TextCNN 在 hard_test 上表现接近（0.8992 vs 0.8988），预训练模型在困难样本上的优势不明显。
- BiLSTM 整体表现最弱，序列建模在短文本分类中优势有限。
- BERT/MacBERT 当前配置（max_len=128, batch_size=8, epochs=5）相对保守，如进一步调参可能有提升空间。

## 四、TextCNN 消融实验结果

| Setting | Test Macro-F1 | Hard Macro-F1 | Hard Improvement vs Baseline |
|---|---|---|---|
| baseline | 0.9160 | 0.8988 | — |
| template_aug | 0.9168 | 0.9089 | +0.0101（+1.01pp） |
| distill_formal | 0.9150 | 0.9083 | +0.0095（+0.95pp） |
| template_aug+distill | 0.9057 | 0.9114 | +0.0126（+1.26pp） |
| llm_real_aug | **0.9244** | 0.9155 | +0.0167（+1.67pp） |
| llm_real_aug+distill | 0.9143 | **0.9259** | **+0.0271（+2.71pp）** |

**分析：**

- 每种改进策略都在 hard_test 上带来了提升，验证了困难样本增强和蒸馏的有效性。
- 真实 LLM 增强（+1.67pp）显著优于模板增强（+1.01pp）。
- 增强与蒸馏存在叠加收益：llm_real_aug+distill（+2.71pp）> 单独增强 + 单独蒸馏的简单加和。
- llm_real_aug 在标准 test 上取得最高 F1（0.9244），llm_real_aug+distill 在 hard_test 上取得最高 F1（0.9259）。

## 六、知识蒸馏实验总结

| 项目 | 说明 |
|---|---|
| 教师模型 | MacBERT formal（hfl/chinese-macbert-base） |
| 学生模型 | TextCNN（~1.37M 参数） |
| 蒸馏损失 | α×CE + (1-α)×T²×KL |
| temperature | 2.0 |
| alpha | 0.5 |
| epochs | 15 |
| patience | 3 |

**教师 logits 规模：**

| 训练集版本 | 样本数 |
|---|---|
| 原始 train | 8249 条 |
| template augmented train | 8273 条 |
| real LLM augmented train | 8308 条 |

**分析：**

- 单独蒸馏将 hard_test F1 从 0.8988 提升到 0.9083（+0.95pp）。
- template_aug+distill 将 hard_test F1 提升到 0.9114（+1.26pp）。
- llm_real_aug+distill 将 hard_test F1 提升到 0.9259（+2.71pp），是所有 TextCNN 实验中困难样本集最优结果。
- llm_real_aug+distill 的标准 test F1 为 0.9143，低于 llm_real_aug 的 0.9244，说明蒸馏更偏向提升困难样本鲁棒性，而不是单纯提升普通测试集整体性能。

## 八、最终核心结论

1. **四模型基线中，TextCNN 在标准测试集表现最佳**，说明在 ChnSentiCorp 这种规模较小的中文短文本任务中，轻量 CNN 模型仍具有竞争力。

2. **困难样本增强能够有效提升模型鲁棒性**。template_aug 将 hard_test F1 从 0.8988 提升到 0.9089（+1.01pp）。

3. **真实 LLM API 增强效果优于模板增强**。llm_real_aug 在 test 上达到最高 F1 0.9244，同时 hard_test F1 提升到 0.9155（+1.67pp）。

4. **大模型增强与知识蒸馏具有叠加收益**。llm_real_aug+distill 在 hard_test 上达到最高 F1 0.9259，相比 baseline 提升 +2.71pp。

5. **蒸馏主要改善困难表达鲁棒性**。llm_real_aug+distill 在普通 test 上略低于 llm_real_aug（0.9143 vs 0.9244），说明蒸馏不是单纯提升整体准确率，而是让模型在复杂语言现象上更稳定。

---

## 九、一句话总结

> 本项目通过真实大模型 API 生成困难样本，并结合 MacBERT 教师模型对 TextCNN 进行知识蒸馏，使困难样本集 Macro-F1 从 0.8988 提升到 0.9259，提升 2.71 个百分点，验证了"大模型辅助困难样本增强 + 轻量蒸馏"在中文短文本情感分析复杂表达鲁棒性提升上的有效性。
