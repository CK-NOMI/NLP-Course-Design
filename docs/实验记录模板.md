## 六、注意事项

1. hard_test 是规则初筛困难集（300 条），不是人工精标金标准。
2. template_generator 是本地模板增强，只用于代码闭环验证。
3. LLM generator 当前 dry-run，真实 API 调用需要单独确认。
4. smoke test 指标不能作为正式实验结论。
5. 正式实验需要统一随机种子 seed=42。
6. BERT/MacBERT 当前配置（epochs=3, batch_size=4, max_len=64）偏轻量，正式实验建议调整。
7. 所有正式结果必须来自真实训练输出，不得编造。
