## 五、终端中文乱码说明

在 Windows PowerShell 中使用 `conda run -n CK python ...` 运行脚本时，日志中的中文会显示为乱码（如"鍔犺浇"等）。这是因为：

- 源码中日志使用 UTF-8 编码
- Windows PowerShell 默认使用 GBK (CP936) 解码终端输出
- 两者编码不匹配导致显示异常

**影响范围：** 仅影响终端显示，不影响代码逻辑、文件输出和实验结果。

**解决方法（可选）：**
- 运行前执行 `chcp 65001` 切换终端编码为 UTF-8
- 或使用 Windows Terminal 并设置 UTF-8 编码
