# 实现方案

> 项目题目：基于大模型辅助困难样本增强与轻量蒸馏的中文短文本情感分析
>
> 版本：v1.0 | 日期：2026-05-19 | 状态：开发中

---

## 1. 项目目标与实现边界

### 1.1 项目最终目标

在 ChnSentiCorp 中文短文本情感二分类任务上，通过困难样本增强与轻量蒸馏策略，提升本地可训练模型在否定、转折、程度变化、隐含主观表达、网络口语等复杂文本上的分类鲁棒性，并形成一套完整的实验对比体系。

### 1.2 实现边界（做什么 / 不做什么）

| 做 | 不做 |
|---|---|
| 训练 TextCNN / BiLSTM / BERT / MacBERT 本地分类模型 | 不用大模型 API 直接做最终分类 |
| 调用大模型 API 生成困难样本、复核标签、评分质量 | 不让大模型参与推理阶段 |
| MacBERT 作为教师模型产生软标签用于蒸馏 | 不追求总体准确率的激进提升 |
| 困难样本子集上的定向提升 | 不从零构建新数据集 |
| 统一数据划分和评价指标下的公平比较 | 不跨数据集迁移 |
| 效率指标（参数量、推理速度）对比 | 不做模型压缩/剪枝/量化 |

### 1.3 核心原则

1. **大模型 API 仅限训练支持**：包括困难样本生成、标签一致性复核、样本质量评分、教师信号辅助。
2. **最终分类器必须是本地模型**：TextCNN / BiLSTM / BERT / MacBERT。
3. **重点是困难样本鲁棒性**：不追求总体 Accuracy 从 95% 到 96%，而是让模型在否定、转折等复杂表达上错误率显著下降。
4. **防止数据泄露**：增强样本只进训练集，困难评估子集只从原始验证/测试集筛选。
5. **统一实验条件**：相同数据划分、相同预处理、相同评价指标、相同随机种子。

- TextCNN/BiLSTM 采用**字级输入**（char-level），不强制依赖 jieba 分词。
- jieba 主要用于误判分析中的关键词提取和规则筛选，属于辅助工具。

- **通义千问 (qwen-max / qwen-plus)**：国内访问稳定，中文能力强

### 4.4 CUDA 建议

- TextCNN/BiLSTM：CPU 即可训练，GPU 加速约 5~10x
- 如果显存不足：降低 batch_size 或使用梯度累积
- 推荐使用学校/实验室 GPU 服务器或 AutoDL / Colab Pro

## 5. 第一步：数据准备模块

### 5.1 数据来源

- 数据集：ChnSentiCorp
- 来源：https://huggingface.co/datasets/lansinuote/ChnSentiCorp
- 加载方式：`datasets.load_dataset("lansinuote/ChnSentiCorp")`

### 5.2 数据字段与标签

| 字段 | 含义 |
|---|---|
| `text` | 中文短文本（评论/反馈） |
| `label` | 情感极性：0=负向，1=正向 |

### 5.3 数据规模

| 划分 | 样本数（约） |
|---|---|
| 训练集 | 9,600 |
| 验证集 | 1,200 |
| 测试集 | 1,200 |

### 5.4 清洗规则

1. **空样本检查**：删除 `text` 为空或全空白的样本
2. **重复样本剔除**：同一划分内去重（text 完全相同）
3. **文本格式统一**：全角转半角标点（可选）、去除多余空格
4. **保留原则**：保留标点、语气词（啊、呢、吧）、口语词（不咋样、还行），因为这些包含情绪线索
5. **不做过度清洗**：不去停用词、不去标点、不做分词（BERT 类模型需要原始文本）

### 5.5 处理后文件格式

```text
data/processed/train.csv
data/processed/dev.csv
data/processed/test.csv
```

CSV 字段：

```text
id,text,label
0,"这个宾馆比较陈旧了，特价的房间也很一般。",0
1,"物流很快，包装也很仔细，整体体验很好",1
...
```

- `id`：从 0 开始的整数索引，在整个数据集内唯一
- `text`：原始中文文本
- `label`：0 或 1

### 5.6 数据泄露防护规则

| 规则 | 说明 |
|---|---|
| 增强样本只加入训练集 | 绝对不能出现在 dev/test 中 |
| 困难评估子集只从 dev/test 筛选 | 不能用增强生成的样本做评估 |
| 增强样本记录 origin_id | 便于追溯，避免与测试集样本"近邻泄露" |
| 训练时 shuffle | 增强样本和原始样本混合后统一 shuffle |

### 5.7 实现脚本

```bash
python scripts/download_data.py    # 下载到 data/raw/
python scripts/preprocess.py       # 清洗输出到 data/processed/
```

### 5.8 验收标准

- [ ] `data/processed/` 下存在 `train.csv`、`dev.csv`、`test.csv`
- [ ] 每个文件有 `id, text, label` 三列
- [ ] 无空样本、无重复样本
- [ ] 标签分布统计打印（正负比例）
- [ ] 总样本数与官方一致（误差 <1%）

## 6. 第二步：基线模型实现

### 6.1 TextCNN

| 项目 | 说明 |
|---|---|
| 作用 | 轻量基线 + 蒸馏学生模型 |
| 输入格式 | 字级 ID 序列，padding 到固定长度 |
| 主要结构 | Embedding → 多尺度 1D Conv (kernel=2,3,4,5) → MaxPool → Concat → Dropout → FC → Softmax |
| 训练目标 | CrossEntropyLoss |
| 推荐超参数 | embed_dim=256, num_filters=128, max_len=256, dropout=0.3, lr=1e-3, batch=64, epochs=15 |
| 保存方式 | `outputs/checkpoints/textcnn_best.pt` (state_dict) |

**构建 vocab：**
- 遍历训练集所有字符，建立 char2id 映射
- 保留出现次数 >= 2 的字符
- 特殊 token: `[PAD]=0`, `[UNK]=1`
- vocab 大小约 4000~5000

**输入处理：**
- 逐字切分（不分词）
- padding/truncation 到 max_len=256
- 转为 LongTensor

### 6.2 BiLSTM

| 项目 | 说明 |
|---|---|
| 作用 | 序列建模基线 + 蒸馏学生模型 |
| 输入格式 | 字级 ID 序列（复用 TextCNN 的 vocab） |
| 主要结构 | Embedding → BiLSTM (2层) → 取最后隐状态拼接 → Dropout → FC → Softmax |
| 训练目标 | CrossEntropyLoss |
| 推荐超参数 | embed_dim=256, hidden_dim=128, num_layers=2, max_len=256, dropout=0.3, lr=1e-3, batch=64, epochs=15 |
| 保存方式 | `outputs/checkpoints/bilstm_best.pt` |

**注意：** BiLSTM 取最后时间步的前向和后向隐状态拼接 `[h_forward[-1]; h_backward[-1]]`，也可以用全序列 attention pooling。

### 6.3 BERT

| 项目 | 说明 |
|---|---|
| 作用 | 中等强度预训练基线 |
| 输入格式 | BertTokenizer 编码，`[CLS] text [SEP]` |
| 主要结构 | `bert-base-chinese` + Linear 分类头 |
| 训练目标 | CrossEntropyLoss |
| 推荐超参数 | max_len=128, lr=2e-5, batch=32, epochs=5, warmup_ratio=0.1, weight_decay=0.01 |
| 保存方式 | `outputs/checkpoints/bert_best/` (save_pretrained) |

**模型来源：** `google-bert/bert-base-chinese` (HuggingFace)

**分类头：**
```python
cls_output = bert_model(input_ids, attention_mask).last_hidden_state[:, 0, :]  # [CLS]
logits = dropout(linear(cls_output))  # (batch, 2)
```

### 6.4 MacBERT

| 项目 | 说明 |
|---|---|
| 作用 | 中文强基线 + 教师模型候选 |
| 输入格式 | BertTokenizer 编码（与 BERT 相同流程） |
| 主要结构 | `hfl/chinese-macbert-base` + Linear 分类头 |
| 训练目标 | CrossEntropyLoss |
| 推荐超参数 | max_len=128, lr=2e-5, batch=32, epochs=5, warmup_ratio=0.1, weight_decay=0.01 |
| 保存方式 | `outputs/checkpoints/macbert_best/` |

**模型来源：** `hfl/chinese-macbert-base` (HuggingFace)

**与 BERT 的区别：**
- MacBERT 使用 MLM 的同义词替换而非 [MASK]，中文表现更好
- 代码结构与 BERT 完全相同，只换预训练权重

### 6.5 预测输出文件格式

所有模型统一输出预测结果到：

```text
outputs/predictions/{model}_{split}_predictions.csv
```

字段：

```text
id,text,label,pred,prob_neg,prob_pos,is_correct
0,"这个宾馆比较陈旧了",0,0,0.82,0.18,True
1,"物流很快包装仔细",1,1,0.05,0.95,True
2,"环境不错但服务差",0,1,0.35,0.65,False
```

## 7. 第三步：统一训练与评估框架

### 7.1 统一训练入口

```bash
python scripts/train.py --model textcnn --config configs/textcnn.yaml
python scripts/train.py --model bilstm --config configs/bilstm.yaml
python scripts/train.py --model bert --config configs/bert.yaml
python scripts/train.py --model macbert --config configs/macbert.yaml
```

可选参数：
```bash
--train_file data/processed/train.csv    # 默认原始训练集
--dev_file data/processed/dev.csv
--exp_name textcnn_baseline              # 实验名称（决定输出子目录）
--seed 42                                # 随机种子
--gpu 0                                  # GPU 编号
```

### 7.2 训练过程记录

每次训练自动记录：

| 项目 | 保存位置 |
|---|---|
| train loss (每 epoch) | `outputs/logs/{exp_name}/train_log.jsonl` |
| dev loss (每 epoch) | 同上 |
| dev accuracy (每 epoch) | 同上 |
| dev macro-f1 (每 epoch) | 同上 |
| best checkpoint | `outputs/checkpoints/{exp_name}/` |
| config 快照 | `outputs/logs/{exp_name}/config.yaml` |
| 随机种子 | 记录在 config 中 |
| 训练时间 | 记录在 log 结尾 |

## 10. 第六步：增强样本质量控制

### 10.1 筛选流水线

```text
候选增强样本 (aug_candidates.jsonl)
    │
    ▼
[1] 标签一致性检查 ──→ 不一致则剔除
    │
    ▼

    │
    ▼
[3] 语义偏移检查 ──→ 偏离主题则剔除
    │
    ▼
[4] 语言自然度检查 ──→ 评分过低则剔除
    │
    ▼
[5] 人工抽查 ──→ 修正边界案例
    │
    ▼
合格增强样本 (aug_train.csv + aug_train_metadata.jsonl)
```

### 10.2 各步骤实现方法

#### 步骤 1：标签一致性检查

**方法：** 双重验证

1. **大模型复核**：用标签一致性 Prompt（9.3.6）让大模型判断改写后文本的情感极性
2. **本地强模型预测**：用已训练好的 MacBERT 预测改写后文本的标签

**通过条件：** 两者预测结果都与原始标签一致

```python
def check_label_consistency(aug_text, original_label, macbert_model, llm_client):
    # 大模型判断
    llm_label = llm_client.predict_sentiment(aug_text)
    # MacBERT 判断
    macbert_label = macbert_model.predict(aug_text)
    # 双重一致才通过
    return (llm_label == original_label) and (macbert_label == original_label)
```

#### 步骤 2：重复度检查

**方法：** 字符级 n-gram 相似度 + 编辑距离

```python
from difflib import SequenceMatcher

def check_duplicate(origin_text, aug_text, threshold=0.85):
    ratio = SequenceMatcher(None, origin_text, aug_text).ratio()
    # 相似度过高（>0.85）说明改写不够，剔除
    # 相似度过低（<0.3）说明可能完全跑偏，也剔除
    return 0.3 <= ratio <= threshold
```

**通过条件：** 相似度在 [0.3, 0.85] 区间内

#### 步骤 3：语义偏移检查

**方法（二选一）：**

- **方案 A：关键词重合度**：提取原文和改写文的 top-5 关键词，重合率 >= 60% 即通过
- **方案 B：Embedding 余弦相似度**：用 MacBERT 的 [CLS] 向量计算余弦相似度，>= 0.7 即通过

推荐方案 B，更鲁棒：

```python
def check_semantic_shift(origin_text, aug_text, model, tokenizer, threshold=0.7):
    emb_origin = get_cls_embedding(origin_text, model, tokenizer)
    emb_aug = get_cls_embedding(aug_text, model, tokenizer)
    sim = cosine_similarity(emb_origin, emb_aug)
    return sim >= threshold
```

#### 步骤 4：语言自然度检查

**方法：** 大模型质量评分（9.3.7 Prompt）

**通过条件：** quality_score >= 3（满分 5）

#### 步骤 5：人工抽查

- 每类增强抽查 5%~10% 样本
- 检查改写是否自然、标签是否正确
- 记录抽查结果，用于评估自动筛选的准确性

## 13. 第九步：轻量蒸馏模块

### 13.1 蒸馏框架

```text
教师模型 (MacBERT, frozen)
    │
    │ 输出 teacher_logits (保存为 .npy)
    │
    ▼
学生模型 (TextCNN / BiLSTM)
    │
    │ 同时学习：硬标签 + 教师软标签
    │
    ▼
蒸馏损失 = α * CE + (1-α) * T² * KL
```

### 13.2 蒸馏损失函数

```text
Loss = α * CE(student_logits, hard_label)
     + (1 - α) * KL(softmax(student_logits / T), softmax(teacher_logits / T)) * T²
```

| 符号 | 含义 | 推荐初始值 |
|---|---|---|
| CE | 硬标签交叉熵损失 | - |
| KL | KL 散度（学生分布 vs 教师分布） | - |
| T | 温度系数，使输出更平滑 | T=3 |
| α | 硬标签损失权重 | α=0.3 |
| 1-α | 软标签损失权重 | 0.7 |

**为什么要乘 T²：** 温度缩放后 softmax 输出的梯度会缩小 1/T²，乘回来保持梯度量级一致。

### 13.3 代码实现（src/distillation/loss.py）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DistillationLoss(nn.Module):
    def __init__(self, alpha=0.3, temperature=3.0):
        super().__init__()
        self.alpha = alpha
        self.temperature = temperature
        self.ce_loss = nn.CrossEntropyLoss()

    def forward(self, student_logits, teacher_logits, hard_labels):
        # 硬标签损失
        ce = self.ce_loss(student_logits, hard_labels)

        # 软标签蒸馏损失
        student_soft = F.log_softmax(student_logits / self.temperature, dim=-1)
        teacher_soft = F.softmax(teacher_logits / self.temperature, dim=-1)
        kl = F.kl_div(student_soft, teacher_soft, reduction='batchmean')
        kl = kl * (self.temperature ** 2)

        # 总损失
        loss = self.alpha * ce + (1 - self.alpha) * kl
        return loss
```

## 20. 关键风险与解决方案

| 风险 | 可能性 | 影响 | 解决方案 |
|---|---|---|---|
| **大模型 API 不稳定** | 中 | 增强样本生成受阻 | ①封装重试机制(3次) ②设置请求间隔(1~2s) ③准备备选 API(如从 OpenAI 切到通义) ④提前批量生成，不依赖实时调用 |
| **增强样本质量差** | 中 | 引入噪声降低性能 | ①严格五步筛选 ②质量评分阈值可调 ③如整体质量不达标，降低增强比例 ④先做小批量试验验证质量 |
| **MacBERT 训练成本较高** | 低 | GPU 显存不足 | ①降 batch_size 到 16 ②使用梯度累积 ③使用 fp16 混合精度 ④借用实验室/云 GPU |
| **蒸馏提升不明显** | 中 | 核心实验结论弱 | ①调整 T 和 α ②使用增强训练后的更强教师 ③增大蒸馏训练轮数 ④如果确实不明显，诚实报告并分析原因（也是有效结论） |
| **总体准确率下降** | 低 | 增强/蒸馏引入负面影响 | ①检查增强样本质量 ②降低增强比例 ③分析是哪类增强导致 ④保留原始基线作为对照说明 |
| **数据泄露** | 低 | 实验结果不可信 | ①代码中硬编码检查(assert) ②增强样本 ID 从 10000 开始 ③不允许从 test 生成增强 ④代码审查 |
| **时间不够** | 高 | 无法完成全部实验 | ①严格按优先级执行(P0→P1→P2) ②先保 MVP ③消融实验只在 TextCNN 上做 ④并行分工 |
| **GPU 不足** | 中 | BERT/MacBERT 训练慢 | ①使用 AutoDL/Colab ②TextCNN/BiLSTM 用 CPU ③BERT 类模型降 max_len 到 64 ④减少 epoch 用 early stopping |
| **预训练模型下载慢** | 低 | 环境搭建受阻 | ①使用国内镜像(hf-mirror.com) ②提前下载到本地 ③团队内共享模型文件 |
| **团队协作冲突** | 中 | 代码/数据冲突 | ①约定目录和接口规范 ②用 git branch 分工 ③config 文件标准化 ④定期同步 |
