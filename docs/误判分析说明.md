# 误判分析与困难样本初筛说明

> 更新日期：2026-05-19（规则收紧版）

---

## 一、模块用途

本模块用于：
1. 从模型预测文件中提取误判样本，按困难类型进行规则初筛；
2. 从 dev/test 集中筛选困难样本，构造困难评估子集候选。

为后续困难样本增强和困难评估集构造做准备。

---

## 二、困难类型定义

| 类型编号 | 类型名称 | 英文标识 | 语言现象 |
|---|---|---|---|
| 1 | 否定类 | negation | 否定词改变情感极性 |
| 2 | 转折类 | transition | 前后情感矛盾，以后半句为主 |
| 3 | 程度变化类 | degree | 程度副词影响判断 |
| 4 | 口语扰动类 | colloquial | 网络用语/口语化/缩写 |
| 5 | 隐含主观类 | implicit | 无明显情感词但暗含态度 |
| 6 | 其他类 | other | 不属于以上分类 |

优先级：transition > negation > degree > colloquial > implicit > other

---

## 三、规则关键词（收紧版）

### 否定类 negation
多字短语：没有、不是、并不、不太、不怎么、算不上、谈不上、不满意、不推荐、不值得、不好、不行、不舒服、不喜欢、不会再、再也不、没意思、没感觉、没达到、没想到、不想再

注意：单字"不"不再单独触发否定类判定。

### 转折类 transition
短语：但是、不过、然而、可是、只是、虽然、尽管、倒是、问题是、遗憾的是、美中不足
正则：但+逗号/空格、但还是、但总体、但价格、但服务、但质量、但环境、却

注意：单字"但"不再单独触发转折类判定。

### 程度变化类 degree
短语：非常、特别、极其、十分、相当、超级、巨、贼、很不、太不、有点失望、有点差、有点贵、有点慢、稍微差、略微失望
正则：太+形容词（好/差/贵/慢/脏/吵/小/远/近/冷/热/难）

注意：单独"很""挺""比较"不再触发程度类判定。

### 口语扰动类 colloquial
短语：哈哈、呵呵、emmm、无语、踩雷、避雷、一般般、不咋样、还行吧、就那样、离谱
正则：3个以上连续英文字母、重复哈、多个句号、多个感叹号、666、yyds、啥、咋

### 隐含主观类 implicit
短语：再也不会、下次不会、以后不会、值得、浪费、白来、回购、推荐、避雷、踩雷、物有所值、性价比、名不副实

## 四、使用命令

### 误判分析

```powershell
conda run -n CK python scripts/error_analysis.py --pred_file outputs/predictions/textcnn_test_predictions.csv --model_name textcnn --output_dir outputs/error_analysis
```

### 困难评估集初筛

```powershell
conda run -n CK python scripts/build_hard_eval.py --input_file data/processed/test.csv --output_file data/hard_eval/hard_test.csv --max_total 300 --max_per_type 80
```

参数说明：
- `--input_file`：输入 CSV 文件（应为 dev.csv 或 test.csv）
- `--output_file`：输出困难样本 CSV
- `--include_other`：可选，是否保留 other 类型（默认不保留）
- `--max_per_type`：每类最多保留多少条（默认 80）
- `--max_total`：总数最多保留多少条（默认 300）
- `--min_text_len`：最短文本长度（默认 6，过短文本除非命中强规则否则排除）

## 五、输出文件说明

### error_analysis.py 输出

| 文件 | 字段 | 说明 |
|---|---|---|
| `{model}_error_samples.csv` | id,text,label,pred,prob_neg,prob_pos,is_correct,hard_type,rule_hits | 误判样本明细 |
| `{model}_error_type_stats.csv` | hard_type,count,ratio | 误判类型统计 |
| `{model}_summary.json` | total_samples, error_samples, accuracy, error_rate, type_distribution | 汇总信息 |

### build_hard_eval.py 输出

| 文件 | 字段 | 说明 |
|---|---|---|
| `hard_test.csv` | id,text,label,hard_type,rule_hits | 困难样本评估集候选 |
| `hard_test_stats.csv` | hard_type,count,ratio | 类型统计 |

## 七、注意事项

1. **当前 hard_test.csv 是规则初筛候选集，不是最终人工标注金标准。**
2. 后续需要人工复核确认困难类型。
3. 已收紧关键词规则，避免单字"不""但""很"等过宽匹配。
4. 默认最多保留 300 条，每类最多 80 条，按比例均匀采样。
5. 困难评估集只能从 dev/test 中筛选，不允许使用增强样本或训练集。
6. 后续正式报告中应说明该困难集构造方法和局限。
7. 一条文本可能命中多个类型关键词，当前按优先级只取最高优先级类型。
