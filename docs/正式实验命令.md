# 正式实验命令

> 本文件整理所有模型的正式训练和评估命令。
> 所有命令在 Windows PowerShell 下执行，使用 CK conda 环境。
> 正式训练不加 max_train_samples、max_dev_samples、max_test_samples、override_epochs。

---

## 一、TextCNN

### 训练

```powershell
conda run -n CK python scripts/train.py --model textcnn --config configs/textcnn.yaml --exp_name textcnn_baseline
```

### 评估

```powershell
conda run -n CK python scripts/evaluate.py --model textcnn --config configs/textcnn.yaml --checkpoint outputs/checkpoints/textcnn_baseline/best.pt --test_file data/processed/test.csv --output outputs/predictions/textcnn_test_predictions.csv
```

## 五、输出文件说明

### 预测文件

| 模型 | 预测文件路径 |
|---|---|
| TextCNN | `outputs/predictions/textcnn_test_predictions.csv` |
| BiLSTM | `outputs/predictions/bilstm_test_predictions.csv` |
| BERT | `outputs/predictions/bert_test_predictions.csv` |
| MacBERT | `outputs/predictions/macbert_test_predictions.csv` |

预测文件字段：`id,text,label,pred,prob_neg,prob_pos,is_correct`

| BiLSTM | `outputs/metrics/bilstm_test_metrics.json` |
| BERT | `outputs/metrics/bert_test_metrics.json` |
| MacBERT | `outputs/metrics/macbert_test_metrics.json` |

### Checkpoint 文件

| BERT | `outputs/checkpoints/bert_baseline/best.pt` |
| MacBERT | `outputs/checkpoints/macbert_baseline/best.pt` |

### 训练日志

| 模型 | 日志路径 |
|---|---|

| MacBERT | `outputs/logs/macbert_baseline/train_log.jsonl` |

## 六、注意事项

1. BERT 和 MacBERT 首次运行会从 HuggingFace 下载预训练权重，需要网络连接。
2. BERT/MacBERT 正式训练配置为 epochs=3、batch_size=4、max_len=64，如需调整请修改对应 yaml。
3. 所有 `outputs/` 下的文件不提交到版本管理。
4. 正式训练前建议清理 smoke test 产生的 outputs 文件。
