## 五、复现最终汇总表命令

```powershell
conda run -n CK python scripts/collect_final_experiments.py
```

此命令会读取 `outputs/metrics/` 下的 JSON 文件，重新生成 reports 和 figures。

---

## 六、注意事项

1. 除非需要重新实验，否则不要重新训练 BERT/MacBERT（每次约 15 分钟）。
2. 不要重新调用 LLM API，增强样本已持久化在 `data/augmented/` 下。
3. 如果只需要查看结果，直接读取 `outputs/reports/` 和 `outputs/figures/`。
4. 如果需要重新评估某个模型，使用对应的 checkpoint 和 evaluate.py。
5. 所有实验基于 seed=42，保证可复现。
