# 知识蒸馏模块说明

> 更新日期：2026-05-19

---

## 一、模块用途

将教师模型（BERT/MacBERT）的知识迁移给轻量学生模型（TextCNN/BiLSTM），使学生模型在不增加参数量的情况下获得更好的分类性能。

---

## 二、蒸馏损失公式

```
Loss = α * CE(student_logits, hard_labels)
     + (1 - α) * T² * KL(log_softmax(student_logits / T), softmax(teacher_logits / T))
```

| 符号 | 含义 | 默认值 |
|---|---|---|
| CE | 硬标签交叉熵损失 | - |
| KL | KL 散度 | - |
| T | 温度系数 | 2.0 |
| α | 硬标签权重 | 0.5 |
| 1-α | 软标签权重 | 0.5 |

**T² 的作用：** 温度缩放后 softmax 输出的梯度会缩小 1/T²，乘回来保持梯度量级一致。

---

## 三、教师 Logits 文件格式

文件路径：`data/distillation/teacher_logits_train.csv`

| 字段 | 说明 |
|---|---|
| id | 样本 id（与 train.csv 对齐） |
| text | 文本 |
| label | 标签 |
| logit_0 | 教师模型负向 logit（未经 softmax） |
| logit_1 | 教师模型正向 logit（未经 softmax） |
| prob_0 | 教师模型负向概率 |
| prob_1 | 教师模型正向概率 |

## 四、使用命令

### 生成教师 logits

```powershell
cmd /c "set HF_HUB_OFFLINE=1&& set TRANSFORMERS_OFFLINE=1&& conda run -n CK python scripts/generate_teacher_logits.py --teacher_model bert --config configs/bert.yaml --checkpoint outputs/checkpoints/bert_baseline/best.pt --input_file data/processed/train.csv --output_file data/distillation/teacher_logits_train.csv"
```

### 蒸馏训练

```powershell
conda run -n CK python scripts/train_distilled.py --config configs/distill.yaml --student_model textcnn --teacher_logits_file data/distillation/teacher_logits_train.csv --exp_name textcnn_distill
```

---

## 五、注意事项

1. 当前 smoke test 使用 `bert_gpu_smoke/best.pt` 作为教师，只验证代码闭环。
2. 正式实验应使用 MacBERT 或 BERT 正式教师模型。
3. 教师 logits 文件的 id 必须与训练集 id 完全匹配。
4. 蒸馏训练不修改教师模型，教师模型始终 frozen。
5. Dev 集评估使用普通 CE loss，不使用教师 logits。
