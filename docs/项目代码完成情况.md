## 八、环境说明

| 环境 | 用途 | torch | transformers | CUDA |
|---|---|---|---|---|
| CK | BERT/MacBERT 训练 + 全部脚本 | 2.5.1+cu118 | 4.57.6 | ✅ RTX 3060 |
| scosparc | TextCNN/BiLSTM 训练（GPU） | 1.10.1+cu113 | 4.12.5 | ✅ RTX 3060 |

注意：scosparc 的 transformers 4.12.5 不支持 safetensors，不能用于 BERT/MacBERT。
后续所有命令统一使用 CK 环境：`conda run -n CK python ...`
